# Matter Overview Command Center

This slice introduces a backend-derived command surface for each matter.

It answers:
- what state is this matter in?
- what deadlines/obligations are urgent?
- what approvals are blocking work?
- which documents are authoritative?
- what drafts are still under review?
- are any substantive client communications unapproved?
- who is responsible?
- what is outstanding financially?
- what security/ethical-wall controls apply?
- what recently happened on the matter?

The route is protected by the existing TSIDEK matter-scope and membership rules.

The command center is intentionally additive. Existing MatterWorkspace tabs remain
available while they are progressively migrated from fallback/prototype behavior
to governed backend truth.
